================================================================================
              NPE Tool V6 局域网共享部署手册（方式一：单人运行）
================================================================================

一、部署原理
--------------------------------------------------------------------------------
  1. 指定一台电脑作为"服务器"运行 NPE Tool 程序
  2. 该电脑启动后开放 8080 端口，局域网内所有工程师通过浏览器访问
  3. 所有数据保存在同一个 npe.db 文件中，实现多人共享
  4. 不需要另外安装数据库软件，SQLite 数据库内嵌在程序中

二、环境要求
--------------------------------------------------------------------------------
  【服务器端】（只需一台电脑，建议配置较好的台式机或笔记本）
    - Windows 7/10/11 操作系统
    - 方案A：已安装 Python 3.10+  → 直接运行 python start.py
    - 方案B：未安装 Python         → 使用 PyInstaller 打包后的 NPE_Tool.exe
    - 电脑需要一直开机，关机后其他人无法访问
    - 建议固定该电脑的局域网 IP（在路由器中绑定 MAC 地址）

  【客户端】（所有使用该工具的工程师）
    - 任意操作系统（Windows / Mac / Linux）
    - 任意现代浏览器（Chrome / Edge / Firefox）
    - 不需要安装 Python、Flask 或任何其他软件
    - 只需要能访问局域网即可

三、部署前准备
--------------------------------------------------------------------------------
  1. 确认局域网连通性
     在"服务器"电脑上，按 Win+R，输入 cmd 回车，执行：

         ipconfig

     记录下"IPv4 地址"，例如：192.168.1.105
     这个地址就是其他工程师访问时需要用到的地址。

  2. 建议固定服务器电脑的局域网 IP
     如果每次开机 IP 地址都会变（如 192.168.1.105 变成 192.168.1.108），
     其他工程师需要重新记地址。建议在路由器管理后台将该电脑的 MAC 地址
     与固定 IP 绑定。

四、部署方式 A：Python 源码运行（服务器端有 Python）
--------------------------------------------------------------------------------
  步骤 1：将 npe_app 文件夹复制到服务器电脑的任意位置
          （例如 D:\Tools\npe_app\）

  步骤 2：安装依赖（首次只需执行一次）
          在 npe_app 文件夹中打开 CMD，执行：

              pip install -r requirements.txt

  步骤 3：启动程序
          在 npe_app 文件夹中执行：

              python start.py

          看到以下输出表示启动成功：
              Server running at http://localhost:8080

  步骤 4：首次初始化
          用浏览器访问 http://localhost:8080/setup
          选择管理员用户名并设置密码，完成初始账号创建。

  步骤 5：验证局域网访问
          在另一台电脑上打开浏览器，访问：

              http://192.168.1.105:8080

          （将 192.168.1.105 替换为实际的服务器 IP）
          如果能看到登录页面，说明部署成功。

五、部署方式 B：PyInstaller 打包 EXE（服务器端无 Python）
--------------------------------------------------------------------------------
  步骤 1：在有 Python 的电脑上打包（只需一次）
          安装 PyInstaller：

              pip install pyinstaller

          进入 npe_app 文件夹，执行 build.bat（或手动执行以下命令）：

              pyinstaller --onedir --name NPE_Tool ^
                  --add-data "templates;templates" ^
                  --clean ^
                  start.py

          打包完成后，会生成 dist\NPE_Tool\ 文件夹。

  步骤 2：将 dist\NPE_Tool\ 整个文件夹复制到服务器电脑的任意位置
          （例如 D:\Tools\NPE_Tool\）

  步骤 3：启动程序
          在服务器电脑上，双击 NPE_Tool.exe
          看到黑色命令窗口显示 "Server running at http://localhost:8080"
          表示启动成功，浏览器会自动打开。

  步骤 4：首次初始化
          用浏览器访问 http://localhost:8080/setup
          创建初始管理员账号。

  步骤 5：其他工程师通过浏览器访问
          http://<服务器IP>:8080

六、数据库共享说明
--------------------------------------------------------------------------------
  【默认情况】
    npe.db 数据库文件位于程序运行的根目录下。
    如果程序文件夹放在公共盘（如 \\共享盘\NPE_Tool\），
    数据库文件自然也在公共盘上，所有数据共享。

  【进阶：指定数据库路径】
    如果希望将数据库单独存放在公共盘的指定文件夹，
    可以在启动前设置环境变量 NPE_DB_PATH：

    CMD 方式：
        set NPE_DB_PATH=\\共享盘\数据文件夹\npe.db
        python start.py

    PowerShell 方式：
        $env:NPE_DB_PATH="\\共享盘\数据文件夹\npe.db"
        .\NPE_Tool.exe

    这样数据库就和程序分离了，便于备份和管理。

七、Windows 防火墙设置
--------------------------------------------------------------------------------
  如果其他电脑无法访问，很可能是防火墙拦截了 8080 端口。

  解决方法：
  1. 按 Win+R，输入 wf.msc 回车，打开"高级安全 Windows Defender 防火墙"
  2. 左侧点击"入站规则"，右侧点击"新建规则"
  3. 选择"端口"，下一步
  4. 选择"TCP"，输入端口号 8080，下一步
  5. 选择"允许连接"，下一步
  6. 勾选"域"、"专用"、"公用"，下一步
  7. 输入名称：NPE Tool 8080，点击完成

  或者更简单的方法：临时关闭防火墙（仅限受信任的局域网环境）

八、日常使用流程
--------------------------------------------------------------------------------
  1. 每天早上，服务器电脑开机后，双击 NPE_Tool.exe（或执行 python start.py）
  2. 浏览器自动打开，管理员可以登录进行日常操作
  3. 其他工程师在自己的电脑上打开浏览器，输入 http://<服务器IP>:8080
  4. 各自登录自己的账号，创建/编辑项目
  5. 所有人看到的数据实时同步
  6. 下班时，服务器电脑可以关机（数据已保存在 npe.db 中，不会丢失）

九、数据备份
--------------------------------------------------------------------------------
  npe.db 就是一个普通的文件，备份非常简单：
  - 直接复制 npe.db 到其他位置即可
  - 建议每天下班前复制一份到安全位置
  - 文件名可以加上日期，如 npe_2026-07-16.db

十、常见问题
--------------------------------------------------------------------------------
  Q1：启动时提示 "Port 8080 is already in use"
      A：说明 8080 端口被其他程序占用。先关闭之前的 NPE 窗口，再重新启动。

  Q2：其他电脑浏览器显示 "无法访问此页面"
      A：检查以下几点：
         - 服务器电脑是否已启动程序（命令窗口是否还在）
         - 两台电脑是否在同一局域网
         - Windows 防火墙是否放行 8080 端口
         - 输入的 IP 地址是否正确（在服务器上 ipconfig 确认）

  Q3：可以同时在多台电脑上运行 NPE_Tool.exe 吗？
      A：可以运行，但不推荐。每台电脑会启动独立的数据库实例，
         数据互不相通。方式一的核心就是"只让一台电脑运行"。

  Q4：PyInstaller 打包后的文件夹很大，可以压缩分发吗？
      A：可以。将 dist\NPE_Tool\ 文件夹压缩成 zip，放到公共盘。
         其他工程师下载后解压，双击 NPE_Tool.exe 即可。
         但注意：如果服务器电脑没有 Python，需要用已经打包好的版本运行。

  Q5：如何修改端口号？
      A：编辑 start.py 和 app.py，将 8080 改为其他端口号（如 5000 或 8888）。
